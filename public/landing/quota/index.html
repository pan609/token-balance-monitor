常见问题

关于 Codex / Claude Code 额度窗口的接入方式、重置时间和数据边界。

怎么看 Claude Code 的 5 小时 / 每周额度窗口？

在 Claude Code 的 status line 里配置项目提供的 bridge 脚本，Claude Code 会把 rate_limits 字段传给脚本并上报到你的服务端，然后就能在 Watch、iPhone 或菜单栏查看剩余比例和重置时间。

支持 Codex 的额度吗？

支持。Codex 的 5 小时和每周 rate limits 从本机 Codex app-server 读取；当服务端能访问本机 Codex 登录态时，还可以触发实时刷新。

额度重置时间怎么算？

重置时间直接来自官方返回的 resets_at 字段（Unix 时间戳），AI Quota 按窗口原样展示重置时间，不做自行估算。

需要提供 Claude 账号密码或登录态吗？

不需要。不读取 Claude 登录文件、不抓取网页，只上报额度窗口的剩余百分比和重置时间；上报使用独立的 ingest token。

额度数据是实时的吗？

尽量新鲜但可能滞后。Claude Code 未运行或电脑离线时只保留最后一次快照，超过新鲜度窗口会明确标记“可能过期”，不伪装实时。

订阅额度和 API 余额是一回事吗？

不是。5 小时 / 每周窗口是订阅制的 rate window，与 API Key 余额、credits 属于不同数据类型；余额监控请使用 AI Balance。
