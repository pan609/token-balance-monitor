关于 AI Meter

AI Meter 是什么？

AI Meter 是开源、自托管的 AI 用量监控套件，包含两条产品线：AI Balance 负责模型平台余额与请求级 token 用量，AI Quota 负责 Codex / Claude Code 的订阅额度窗口。

AI Meter 开源吗？怎么部署？

开源，采用 MIT License，代码托管在 GitHub。clone 仓库后复制 .env.example 为 .env、按需填入平台 key，即可在自己的机器上启动 Web 看板等入口。

我的 API Key 和用量数据存在哪里？

云厂商 AccessKey 只保存在你自己服务端的 .env，不会打包进浏览器、macOS 客户端或 iPhone App；用量记录只保留结构化字段，不保存 prompt 和 response。

AI Balance 和 AI Quota 有什么区别？

AI Balance 回答“账户里还剩多少钱、哪次请求用了多少 token”；AI Quota 回答“Codex / Claude Code 这一轮订阅额度还剩多少、多久重置”。两类数据分开维护，不混算。

支持哪些使用入口？

Web 看板、Agent Skill、macOS 状态栏与桌宠、iPhone App 与 iOS Widget、Apple Watch App 与表盘 complication，以及本机 bridge 脚本，每个入口都可以独立使用。
