常见问题

关于 AI Balance 的数据来源、刷新频率和隐私边界。

AI Balance 支持哪些模型平台？

目前支持阿里云百炼、DeepSeek、火山引擎 / 豆包、Kimi (Moonshot)、硅基流动和 OpenRouter，由服务端调用各平台官方余额或 credits 接口，也可以按文档自行适配新平台。

余额多久刷新一次？

服务端默认每 60 秒轮询一次各平台余额，间隔可通过 BALANCE_POLL_INTERVAL_MS 调整（最小 60 秒），每条余额都保留最近同步时间。

token 用量能看到什么粒度？

请求级。每条 usage 事件记录 provider、model、tokens、project、account、resource 和时间戳，可以按项目、模型、账号或资源聚合，定位具体消耗来源。

会保存我的 prompt 和模型回复吗？

不会。AI Balance 只记录结构化用量字段，不保存 prompt、response 或业务正文；云厂商 key 也始终留在服务端，不下发到任何客户端。

不同币种的余额怎么汇总？

只有 CNY（或平台显式给出的人民币金额）计入人民币总额；OpenRouter 等 USD credits 按原币种单独显示，不做汇率折算后混入总额。

Codex / Claude Code 的订阅额度也在这里看吗？

不在。5 小时、每周订阅额度窗口属于另一条产品线 AI Quota，它不进入 AI Balance 的余额汇总，也不和 credits 混算。
